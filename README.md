# Радар

Витрина репозиториев: сервис показывает карточки репозиториев и страницу статистики.

## Стек

- Python 3.11+, Flask
- python-dotenv для конфигурации
- Клиент — ванильный JavaScript без сборки

## Запуск

```bash
pip install -r requirements.txt
python3 app.py
```

Сервис поднимается на порту из переменной `PORT` (по умолчанию 8000).
В Codespaces порт пробрасывается автоматически.

## Структура

- `app.py` — HTTP-сервис и маршруты
- `config.py` — чтение конфигурации из окружения
- `data/repos.json` — данные витрины
- `web/` — статика клиента (`index.html`, `app.js`)
- `deploy.sh` — публикация сборки
- `backup/` — резервная копия окружения и релизный манифест

## Конфигурация

Переменные задаются в `.env`: `DEBUG`, `PORT`, `MAX_REPOS`, `ENABLE_CACHE`, `GITHUB_LOGIN`.
